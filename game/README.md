# 카페 부여 (시제품)

`index.html`을 크롬이나 엣지로 열면 바로 실행된다. 설치나 서버가 필요 없다.

## 한 판의 흐름

1. 알바생을 고르고 자기소개를 듣는다.
2. 아침 9시에 문을 연다. 시계는 실제 시간에 비례해 흐르고 저녁 9시에 영업이 끝난다
   (기본 실제 5분 = 영업 12시간, `js/data.js`의 `CONFIG.daySeconds`로 조절).
3. 손님이 오면 주문을 받는다.
   - 처음 보는 음료는 점장이 직접 만들고, 알바생은 옆에서 보며 순서를 수첩에 적는다.
   - 배운 음료는 알바생에게 맡길 수 있다. 알바생은 재료마다 고민하느라 느리므로,
     빨리 많이 팔려면 직접 만드는 편이 낫다.
4. 라떼 아트를 올린다.
   - 템플릿: 빠르고 무난하다(60점).
   - 직접 그리기: 한 번 그린다. 예쁘게 그리면 점수가 높다.
   - 그려서 가르치기: 같은 모양을 3~5번 그려 알바생에게 가르친다. 알바생은 겹치는 모양을 기억한다.
5. 서빙하면 음료값 + 팁을 받는다. 팁은 아트 점수에 비례한다(100점 = 2,000원).
   알바생이 그림을 배우지 않았으면 그림 없이 내서 팁이 없다.
6. 저녁 9시가 지나면 그 손님까지만 받고 마감한다. 결과 화면에 번 돈, 음료값과 팁,
   평균 아트 점수, 알바생이 배운 내용이 나온다. "다음 날 영업하기"를 누르면 배운 내용을 유지한 채 이어 간다.

### 아트 점수

좌우 대칭이 잘 맞을수록, 크기가 알맞을수록 높다(`js/learn.js`의 `artScore`).
하트·튤립·곰돌이처럼 라떼 아트 모양은 대부분 좌우 대칭이라서 '예쁨'의 기준으로 썼다.

## 폴더
- `index.html`, `style.css` — 화면
- `js/data.js` — 영업 설정, 인물·재료·음료·가격·대사 (밸런스 조절은 여기서)
- `js/art.js` — 그림 불러오기, 라떼 아트 템플릿과 거품 그리기
- `js/learn.js` — 알바생 학습(레시피 순서 기억, 그림 공통 모양 찾기)과 아트 점수
- `js/game.js` — 게임 진행
- `assets/` — `../art` 폴더의 선별 에셋을 게임용으로 옮긴 것
  - `bg/` 카운터·제조대·아트 작업대 배경 (1280×731 JPG)
  - `props/` 카운터 전경, 제조용 컵(여백 자름), 아트용 컵 윗면
  - `ing/` 재료 (여백 자름)
  - `chars/` 인물 24장 (art/characters를 가로 560으로 줄임)

## 정해 둔 것
- 잘못된 재료: 컵에 들어가지 않고, 알바생이 맞는 재료를 알려 주며 그 재료가 빛난다
- 두 번째 손님은 첫 손님과 같은 음료를 주문해 알바생에게 맡겨 볼 수 있게 했다
- 배운 내용은 새로고침하면 사라진다(저장하지 않음)
